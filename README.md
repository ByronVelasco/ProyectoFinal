# Continuidad Educativa y Predicción con Modelos de Machine Learning

Este proyecto analiza los factores que afectan la continuidad educativa de niños y niñas durante la pandemia del COVID-19, utilizando técnicas de análisis exploratorio de datos y modelos de clasificación supervisada. Se trabajó con un dataset internacional que recoge información proporcionada por cuidadores, incluyendo aspectos socioeconómicos, educativos, geográficos y demográficos.

## Objetivos del Proyecto

### Objetivo General

Analizar los factores socioeconómicos, educativos y demográficos que inciden en la situación educativa de niños durante la pandemia del COVID-19, y desarrollar un modelo predictivo para clasificar su situación escolar.

### Objetivos Específicos

- Realizar una limpieza y transformación exhaustiva del dataset original.
- Explorar la relación entre variables clave mediante análisis univariado y multivariado.
- Construir y comparar modelos de clasificación (árbol de decisión, random forest y gradient boosting) para predecir la situación educativa.

## Conclusiones

- Las variables más determinantes en la situación educativa son: edad del niño, situación económica, nivel educativo del cuidador y tipo de institución educativa.
- Los modelos de **Decision Tree** y **Gradient Boosting** alcanzaron el mejor desempeño con una precisión del **54%** y un F1 ponderado de **0.49**, superando a Random Forest.
- La estructura del hogar y la condición socioeconómica mostraron una fuerte asociación con la continuidad o interrupción del proceso educativo.
- Aunque el modelo predictivo no logró altos niveles de precisión en todas las clases, ofrece una herramienta útil para identificar patrones críticos y orientar políticas públicas educativas más focalizadas.
